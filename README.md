# AI Trip Planner

**Created and customized by Adhya Singh**

AI Trip Planner is a smart, modern web application that helps you plan your trips, discover new places, and manage your journeys with ease. Powered by advanced AI and built with React and Vite, this project features a beautiful UI, interactive maps, and seamless user experience.

## Features
- AI-powered trip planning and recommendations
- Interactive maps and place discovery
- User-friendly interface with modern design
- Trip management and itinerary tracking
- Built with React, Vite, and Tailwind CSS

## Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
